# INT Helper

ปลั๊กอินที่ให้ Codex ช่วยทำแบบฝึกหัดบน INT Project และ Virtual School ผ่าน Chrome เปิดวิชาที่จะทำ แล้วบอก Codex ได้เลยว่าอยากให้ช่วยตรงไหน อ่านได้ทั้งโจทย์ข้อความและรูปภาพ ไม่ต้องมี API key เพิ่ม

[ดาวน์โหลดรุ่นล่าสุด](https://github.com/Topmoaman/int-helper/releases/latest) · [ประวัติการเปลี่ยนแปลง](https://github.com/Topmoaman/int-helper/blob/main/CHANGELOG.md)

## ใช้ทำอะไรได้บ้าง

จะให้ช่วยอธิบายโจทย์ข้อเดียว ทำต่อให้จบบท หรือไล่ทำวิชาที่ยังค้างอยู่ก็ได้ แค่บอกวิชาหรือบทให้ชัด ไม่ต้องจำคำสั่ง เช่น

> ช่วยทำบทที่ 3 ให้หน่อย ตอบให้ครบแล้วรอฉันตรวจและกดส่งเอง

> ทำวิชาที่ยังค้างในหน้านี้ต่อให้ครบ ส่งให้ได้เลย

> ดูเฉลยรอบเมื่อกี้ให้หน่อยว่าผิดตรงไหน แล้วจำคำตอบที่ถูกไว้ด้วย

ถ้าทำปลายภาค จะตั้งเวลาให้กระจายการตอบก็ได้ เช่น “ค่อย ๆ ทำให้ครบประมาณหนึ่งชั่วโมง” ระบบจะเว้นจังหวะให้ข้อสุดท้ายอยู่ใกล้เวลาที่บอก ตั้งได้สูงสุด 119 นาที แต่ถ้าเว็บโหลดช้าหรือใช้เวลาคิดนานก็อาจเกินได้

**Normal** คือทำหนึ่งรอบ เลือกได้ว่าจะส่งเองหรือให้ Codex ส่งให้ ถ้ายังไม่ได้บอก มันจะถามก่อนเริ่มตอบ

**Loop** คือทำปลายภาคซ้ำในวิชาเดิม โดยตอบ ส่งตรวจ อ่านเฉลย แล้วนำคำตอบที่ยืนยันแล้วมาใช้ในรอบถัดไปจนได้เต็มหรือคุณสั่งหยุด ใช้กับปลายภาค INT 50 ข้อ และปลายภาค Virtual School ตามจำนวนข้อจริง คะแนนเต็มไม่ได้รับประกัน และ Codex ต้องเปิดทำงานอยู่จึงจะทำต่อได้

หลังส่งข้อสอบ Virtual School จะอ่านจากหน้ารวมเฉลย จึงไม่ต้องเปิดทีละข้อ คำตอบที่จำไว้จะต้องผ่านการตรวจว่าเฉลยตรงกับรอบที่ทำก่อน ตอนนี้คลังคำตอบของ Virtual School รองรับเฉลยปลายภาค ส่วนเฉลยก่อน/หลังเรียนอ่านได้แต่ยังไม่เก็บเข้าคลัง

เริ่มงานทั้งบทหรือวิชาจากหน้ารวมบทเรียนของวิชานั้น และใช้กับแบบฝึกหัดที่คุณได้รับอนุญาตให้ใช้ผู้ช่วยได้

## ให้ AI ช่วยติดตั้ง

ต้องมี Codex, Chrome และ Node.js 20 ขึ้นไป ถ้าไม่อยากติดตั้งเอง คัดลอกข้อความนี้ไปให้ Codex หรือ AI ที่จัดการไฟล์และเปิด terminal ในเครื่องคุณได้:

```text
ช่วยติดตั้ง INT Helper จาก https://github.com/Topmoaman/int-helper ให้หน่อย
อ่าน README.md กับ AI-INSTALL.md แล้วติดตั้งรุ่นล่าสุดด้วยตัวติดตั้งของโครงการ
ทำขั้นตอนที่ทำได้ให้เลย บอกโฟลเดอร์ที่ต้องเลือกใน Chrome และส่วนที่ฉันต้องกดเอง
ตรวจว่าเชื่อมต่อกับ Codex ได้ด้วย ยังไม่ต้องเริ่มทำข้อสอบ
```

[คู่มือสำหรับ AI ผู้ติดตั้ง](https://github.com/Topmoaman/int-helper/blob/main/AI-INSTALL.md)

ถ้าติดตั้งเอง ให้ดาวน์โหลด **Source code (zip)** จากหน้า Release แล้วแตกไฟล์ เปิด terminal ในโฟลเดอร์ที่มี `install.mjs` และรัน:

```sh
node install.mjs
```

จากนั้นเปิด `chrome://extensions` เปิด **Developer mode** กด **Load unpacked** แล้วเลือกโฟลเดอร์ที่ตัวติดตั้งบอก รีเฟรชหน้าแบบฝึกหัดและเปิดงาน Codex ใหม่ที่เปิดใช้ INT Helper ถ้ามีส่วนขยายรุ่นเก่าอยู่ ให้ปิดตัวเก่าก่อน

ไม่ต้องรัน `npm install` สำหรับการติดตั้งใช้งาน ไฟล์ `int-helper-update.json` เป็นไฟล์สำหรับระบบอัปเดต ไม่ใช่ไฟล์ที่จะโหลดเข้า Chrome

## อัปเดตและทำงานต่อ

จบงานที่กำลังทำและเก็บเฉลยให้เสร็จก่อนอัปเดต จากนั้นออกจากหน้าข้อสอบ เปิด popup ส่วนขยาย แล้วกด **ตรวจรุ่นใหม่ → อัปเดตตอนนี้** โดยมี Codex ที่เชื่อมต่ออยู่ เมื่อเสร็จแล้วให้รีเฟรชหน้าเว็บและเปิดงาน Codex ใหม่ ผู้ที่ติดตั้งด้วยตัวติดตั้งตั้งแต่ 0.18.0 อัปเดตมารุ่นล่าสุดได้เลย

ถ้าการเชื่อมต่อหลุดระหว่างทำ ให้กลับไปบอก “ทำต่อ” ในงาน Codex เดิมก่อน รุ่นนี้เก็บสถานะไว้เพื่อทำต่อในแท็บและหน้าเดิมได้ อย่าเพิ่งรีโหลดหน้าเว็บหรือส่วนขยาย เพราะอาจทำให้กู้สถานะเดิมไม่ได้ การอัปเดตไม่ได้ปลดล็อกงานที่ค้างจากบั๊กเก่าให้ย้อนหลัง

ถ้า Codex แจ้งว่าหาไฟล์ปลั๊กอินรุ่นเก่าไม่เจอ ให้ปิดแล้วเปิด Codex ใหม่ หากยังไม่ได้ ให้ส่งข้อความผิดพลาดให้ผู้ช่วยตรวจ

## ข้อมูลเก็บที่ไหน

แต่ละคนใช้บัญชีเว็บของตัวเอง โจทย์ที่อ่านจะส่งให้ Codex ใช้ตอบ เมื่อขอให้จำคำตอบหรือใช้ Loop ประวัติและเฉลยจะเก็บในเครื่องที่ `~/.local/share/int-practice-helper/history/` การอัปเดตไม่ลบคลังนี้และไม่ส่งโจทย์ไป GitHub

สถานะสำหรับทำงานต่อเมื่อเชื่อมต่อหลุดเก็บชั่วคราวใน Chrome แยกจากคลังคำตอบ แม้ไม่ได้เปิดการจำก็ยังมีสถานะนี้ อายุไม่เกิน 24 ชั่วโมง และอาจหายเมื่อปิดเบราว์เซอร์หรือรีโหลดส่วนขยาย

โครงการนี้ทำแยกต่างหาก ไม่ได้เป็นของ INT Project หรือ Virtual School และไม่ได้แจกบัญชีหรือคลังคำตอบส่วนตัว
